01 / THE IDEA

A compact foundation
to build on.

ByteC focuses on a small instruction-oriented core and a virtual processor of its own. The project is open source, and its toolchain is implemented in portable C11.

⌘

Instruction-driven

Work with explicit operations, registers, comparisons and jumps. Labels make control flow direct and visible.

01
▦

Custom 64-bit VM

ByteC emulates its own 64-bit processor model with five general-purpose registers and an 8-bit condition register.

02
⌁

C11 toolchain

The compiler, interpreter, installer and uninstaller are written in C11, keeping the implementation close to the language's low-level roots.

02 / ARCHITECTURE

Meet the virtual
processor.

The documented machine model uses five 64-bit general-purpose registers and an 8-bit condition register called ZS.
