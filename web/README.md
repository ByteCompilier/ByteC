# ByteC Website

Static website source for the ByteC programming language.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, code-copy button and footer year
- `favicon.svg` — site icon

## Preview locally

Open `index.html` in a browser. No build step or package installation is required.

## Links

- ByteC source repository: https://github.com/ByteCompilier/ByteC
- Official BPM package catalog: https://bytecompilier.github.io/BPM-registry/
- BPM registry source: https://github.com/ByteCompilier/BPM-registry

The website describes the features documented in the ByteC repository README. It does not claim that proposed or planned VM instructions are already implemented.
